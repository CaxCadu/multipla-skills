# Weekly review

A short, repeatable ritual (30–60 minutes) to get everything captured, current and prioritized. It follows the three phases of the GTD weekly review: **Get Clear, Get Current, Get Creative**. See `references/sources.md`.

## When to use
- The user asks for a "weekly review", "plan my week" or "I'm behind on everything".
- End of the work week or start of a new one.
- Skip it if the user only wants a quick daily to-do list.

## Workflow

Ask the user to paste or describe their current lists (tasks, calendar, notes). Work through the phases in order and keep the user moving; do not turn it into a long discussion.

### 1. Get Clear
1. Collect loose items: notes, paper, screenshots, messages that need a decision.
2. Get inboxes (email, chat, notes) to zero by deciding each item: do now (under 2 minutes), schedule, delegate, file, or drop.
3. Empty your head: ask "what else is on your mind?" and capture every answer as a task or note.

### 2. Get Current
4. Review next-action lists: delete done items, fix vague ones, make each a concrete next physical action.
5. Review the past week's calendar for follow-ups and loose ends.
6. Review the upcoming 2–4 weeks of calendar for prep that must start now.
7. Review the "waiting for" list and decide who to nudge.
8. Review projects (any outcome needing more than one step): each needs at least one next action.
9. Review relevant checklists (recurring responsibilities).

### 3. Get Creative
10. Review "someday/maybe": promote, keep or delete.
11. Ask for one bold idea or improvement for next week.

### Close
Produce the output below and ask the user to confirm the top three priorities.

## Output format

```
## Weekly review: <date range>
**Wins:** 2–3 bullets
**Open loops closed:** count + notable ones
**Next actions by project:** short list per project
**Waiting for:** who / what / follow-up date
**Next week's top 3:** numbered
**Parked (someday/maybe):** bullets
```

## Notes
- Prefer the user's own words and tools; do not force a new system.
- If the user has no lists yet, run only Get Clear and create the first lists from what they capture.
- Keep it concrete: every item ends as a next action, a calendar entry, a waiting-for entry or a deletion.
