# SEO brief

Produces a writer-ready brief for one page. It is based on Google's guidance for **helpful, reliable, people-first content** and its **SEO Starter Guide**. See `references/sources.md`.

## When to use
- "Write an SEO brief / outline for <topic>."
- "Optimize this page for search."
- Not a promise of rankings. No one can guarantee a position in search results.

## Workflow

1. **Collect inputs.** Topic, target audience, goal of the page (inform, compare, sell), the business or author, country/language, and any existing page.
2. **Define the reader's need.** What is the person trying to accomplish when they search this? What would leave them satisfied? Note the words novices vs experts use for the same thing.
3. **Check the people-first test.** The page should offer original information, analysis or first-hand experience, be thorough on its topic, and be made with care. Avoid content made mainly to attract search traffic.
4. **Who / How / Why.**
   - *Who* wrote it (clear byline and author background).
   - *How* it was made (disclose automation or AI use where readers would expect it).
   - *Why* it exists (primarily to help people).
5. **Draft the on-page elements:**
   - a unique, concise **title** that describes the page;
   - a short, unique **meta description** (1–2 sentences; Google may write its own snippet);
   - a clear **heading** structure (H1 and logical sections; no fixed number required);
   - a readable **URL** with real words;
   - **internal links** with descriptive link text to related pages;
   - **images** that are sharp, near related text, with descriptive alt text.
6. **Outline the sections** with the question each one answers and what evidence, example or source goes there.
7. **Add trust signals:** cite sources, show author expertise and experience, keep dates honest (do not change dates just to look fresh).
8. **Flag sensitive topics.** For health, finance, safety or civic topics, require expert review and clear sourcing.

## Output format

```
## SEO brief: <working title>
**Audience & goal:**
**Reader need:** what they want to accomplish
**Who / How / Why:**
**Title:** …  **Meta description:** …  **URL:** …
**Outline:** H1, then H2/H3 with the question each answers
**Evidence to include:** originals, data, examples, sources
**Internal links:** anchor text → target page
**Images:** what, where, alt text
**Do not:** (keyword stuffing, copied summaries, fake authors, date tricks)
```

## Limits
No ranking guarantees. Search guidance changes; check Google Search Central for the current version before relying on details. Keyword volumes and competitor data are not available without a tool; ask the user for them if needed.
